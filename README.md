# Retail Sales Analysis

En este proyecto se aplican técnicas de **Data Science** para identificar patrones, extraer insights y comprender el comportamiento de los clientes. Utiliza un dataset diseñado para simular un entorno de retail dinámico.

---

## 🚀 Descripción del Proyecto

Este repositorio es un espacio de trabajo para realizar un **Análisis Exploratorio de Datos (EDA)** exhaustivo, centrándose en:

* **Ventas de Retail:** Análisis de tendencias y volumen de transacciones.
* **Demografía del Cliente:** Segmentación y características del consumidor.
* **Patrones de Comportamiento:** Identificación de hábitos de compra y preferencias.

---

## 📂 Estructura del Proyecto

* `data/`: Contiene el dataset de ventas y demografía (archivos CSV).
* `notebooks/`: Jupyter Notebooks con el proceso de limpieza y EDA.
* `src/`: Scripts de Python para procesamiento y funciones auxiliares.
* `README.md`: Documentación del proyecto.
